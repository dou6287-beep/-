# QuizFlow

강의안 기반 확인 퀴즈 서비스의 프런트엔드 MVP입니다.

## 실행

`index.html`을 브라우저에서 열면 사용할 수 있습니다. 별도 패키지 설치는 필요하지 않습니다.

## 현재 동작 범위

- PDF 파일 형식과 50MB 제한 확인, 드래그 앤 드롭
- 퀴즈 방 제목, 닉네임, 초대 주소 복사
- 객관식·단답형 퀴즈, 문항 이동, 채점 및 페이지 근거 해설
- 오답 개념 요약과 오답만 다시 풀기
- 리뷰 시간 선택 및 일정 결과 화면
- 모바일·태블릿·데스크톱 반응형 화면

현재 문제 세트는 회로이론 데모 데이터입니다. PDF 내용 추출과 AI 문제 생성, 실제 참여자 간 공유·시간 교집합 계산은 서버/API 연동이 필요한 후속 작업이며 아직 연결되어 있지 않습니다. 업로드한 파일의 실제 페이지 수나 텍스트 인식 여부를 검증하지 않습니다.
